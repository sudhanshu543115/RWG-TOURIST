# 🚀 Ride With Guide (RWG)

## 📌 Overview

Ride With Guide (RWG) is a full-stack tourist guide booking platform that connects tourists with verified local guides for personalized city tours. The platform enables seamless trip booking, secure payments, real-time tracking, guide assignment, and complete tour management through dedicated Tourist, Guide, and Admin portals.

---

## ✨ Key Features

### 👤 Tourist Portal
- OTP-based Authentication & Profile Management
- Multi-step Tour Booking Process
- City & Guide Selection
- Custom Stops & Itinerary Planning
- Wallet Management & Transaction History
- Razorpay Payment Integration
- Real-time Guide Tracking
- Tour Progress Stepper
- Booking History & Status Tracking

### 🧑‍✈️ Guide Portal
- View and Manage Tour Requests
- Accept/Reject Booking Requests
- Live Location Sharing
- Start & Complete Tours
- Earnings Dashboard
- Profile & Availability Management

### 🛠️ Admin Portal
- Guide Verification & Approval
- Booking Management
- Guide Assignment System
- User Management
- Platform Monitoring & Analytics

## 📍 Tour Progress Stepper

The platform includes an interactive trip progress stepper that provides real-time visibility into the tour journey.

### Features
- Completed Stops Tracking
- Current Active Stop Highlighting
- Upcoming Destinations Display
- Real-Time Trip Progress Updates
- Guide & Tourist Synchronization

Example:

```text

✔ Marine Drive
🔄 Chowpatty Beach (Current Stop)
```
